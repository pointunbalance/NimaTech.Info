# موقع شخصي ثابت

صفحة تعريفية بسيطة باللغة العربية يمكن نشرها مباشرة على **GitHub Pages** بدون أدوات بناء إضافية.

## محتويات الصفحة
- قسم ترحيبي مع أزرار للتنقل السريع.
- نبذة عنك وماذا تقدم.
- بطاقات لعرض ثلاثة مشاريع قابلة للتعديل.
- معلومات تواصل وروابط شبكات اجتماعية.

## التخصيص السريع
1. عدّل النصوص في `index.html` (الاسم، الوصف، روابط المشاريع والتواصل).
2. يمكن تغيير الألوان أو الخطوط من ملف `styles.css` حيث تجد المتغيرات في القسم العلوي.
3. لاستبدال الروابط الوهمية، حدّث قيم `href` في عناصر `<a>`.

## النشر على GitHub Pages
1. ادفع الملفات إلى الفرع `main` أو أنشئ فرعًا جديدًا.
2. من إعدادات المستودع في GitHub، اختر **Pages** ثم حدد المصدر `Deploy from a branch` والمسار الجذر (الفرع `main` والمسار `/`).
3. بعد الحفظ سيظهر لك رابط الموقع خلال دقائق مع شهادة HTTPS تلقائيًا.

## التطوير محليًا
يمكن فتح الملف مباشرة في المتصفح بدون خادم:
```bash
open index.html   # على macOS
# أو
xdg-open index.html  # على Linux
```
