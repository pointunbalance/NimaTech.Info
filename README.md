# NimaTech - نظام إدارة المبيعات والحسابات

موقع تعريفي لشركة NimaTech المتخصصة في حلول البرمجيات لإدارة المبيعات والحسابات للأنشطة الصغيرة والمتوسطة.

## 🌟 المميزات

### التصميم
- تصميم عصري مع تأثيرات Glassmorphism
- خلفية متدرجة متحركة مع كرات ضوئية عائمة
- تدرجات لونية جذابة على النصوص والعناصر
- تصميم متجاوب يعمل على جميع الأجهزة
- قائمة تنقل متجاوبة للهواتف المحمولة

### الأنيميشن والتأثيرات
- تأثيرات Hover متقدمة مع Scale و Glow
- Scroll Reveal للعناصر عند التمرير
- Parallax Scrolling لقسم Hero
- تأثير Ripple على الأزرار
- تأثيرات Pulse على العناصر المهمة
- حركة مستمرة للخلفية

### المحتوى
- قسم Hero مع عرض القيمة المضافة
- قسم "لماذا NimaTech؟" مع خطوات التنفيذ
- قسم "من نحن" مع الخدمات المقدمة
- قسم الحلول (وحدات النظام المتكاملة)
- قسم الأسعار مع 3 باقات
- قسم الأنشطة (قطاعات متنوعة)
- نموذج تواصل مع معلومات الاتصال

### التقنيات المستخدمة
- HTML5 دلالي
- CSS3 مع متغيرات و animations
- JavaScript Vanilla للتفاعلية
- خط Cairo العربي
- تصميم RTL للغة العربية

## 📁 هيكل المشروع

```
NimaTech.Info/
├── index.html          # الصفحة الرئيسية
├── styles.css          # ملف التنسيقات
├── script.js           # ملف JavaScript
└── README.md           # التوثيق
```

## 🚀 التشغيل المحلي

### باستخدام Python
```bash
python -m http.server 8000
```

### باستخدام Node.js
```bash
npx serve
```

### فتح مباشرة
يمكن فتح `index.html` مباشرة في المتصفح بدون خادم.

## ⚙️ التخصيص

### تغيير الألوان
في `styles.css`، عدّل متغيرات CSS في القسم العلوي:
```css
:root {
  --brand: #667eea;
  --purple: #a855f7;
  --blue: #4facfe;
  /* ... */
}
```

### تعديل النصوص
جميع النصوص في `index.html` يمكن تعديلها مباشرة.

### تغيير الروابط
حدّث قيم `href` في:
- روابط التنقل في القائمة العلوية
- روابط التواصل الاجتماعي
- رابط نموذج التواصل (FormSubmit)
- رابط واتساب

## 📦 النشر على GitHub Pages

1. ادفع الملفات إلى الفرع `main`
2. من إعدادات المستودع في GitHub، اختر **Pages**
3. حدد المصدر `Deploy from a branch`
4. اختر الفرع `main` والمسار `/`
5. احفظ وانتظر دقائق قليلة
